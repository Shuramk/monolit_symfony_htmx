# Декомпозиция: Monolit → Symfony + HTMX

**Дата:** 2026-08-03  
**ТЗ:** постепенная миграция актуального legacy-монолита без остановки и без повреждения базы.

## Принципы

- Legacy MariaDB остаётся source of truth, пока модуль не переведён целиком.
- Symfony подключается к копии базы через `monolit_reader` только для чтения.
- Никаких `doctrine:schema:*`, автоматических миграций и массового изменения кодировок.
- Новая целевая схема проектируется после инвентаризации, а не выводится автоматически из legacy.

**Done when:**

- `создать: docs/architecture/enterprise-schema.md`
- `создать: migrations/Version*.php`
- `создать: src/Enterprise/Application/ImportLegacyEnterpriseProfile.php`

**Детали:**

Целевая таблица хранит текст в `utf8mb4`, телефоны в отдельной таблице с типом (`sales`, `accounting`), реквизиты VAT/PE — явными полями. Миграция создаёт новые таблицы, не меняет `sklad_enterprise`; импорт идемпотентен и сохраняет исходный `legacy_eid`. Write-экран включается только после сверки данных и явного решения о cutover.

**Done when:**
- [ ] Схема и mapping из legacy утверждены в документе.
- [ ] Миграция является add-only и имеет проверенный rollback.
- [ ] Повторный импорт не создаёт дубликатов.
