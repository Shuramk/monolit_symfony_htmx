# Добавление оплаты заказа

Дата: 2026-10-09. Основание: legacy did=228, CashBox.moneyTaken; согласовано с пользователем.

- Оплата сразу увеличивает orders.prepayment, не создаёт приход в расходную кассу.
- Запись OrderPayment сохраняет автора, дату, сумму, markup заказа, карту и moneyTaken=1.
- Старые moneyTaken (NULL/1/2/3), toCard (NULL/0/1), pCashless переносим отдельно,
  только в существующие записи без повторного импорта заказов и изменения сумм.
- Деньги в кассу передаются позже (3), забираются/инкассируются позже (2).
  Эти операции и раздел касс не входят в текущую задачу.
- Новая форма как legacy: сумма, «внесено на карту» только при markup=0.
- Право просмотра 220, добавления 228; CSRF общий; JSON DTO и User по типу.
- Положительная сумма до 10 целых и 2 дробных знаков; Decimal; отменённый заказ запрещён.
- Переплата разрешена как раньше. Повтор одного UUID с тем же содержимым — без повторной оплаты;
  тот же UUID с другим заказом/автором/суммой/картой — ошибка.
- Под блокировкой заказа одной транзакцией: оплата, prepayment, версия, changelog.
- История «Внесена оплата ...»; оплачено/остаток/печать пересчитываются без двойного учёта.
- Никаких записей в legacy и никаких движений по кассе.
