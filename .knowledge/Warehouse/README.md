# Склад

## Детализация продукции (legacy 104/105/106)

Работает полностью в application БД; legacy только для чтения.

- /warehouse/products — прежний обзор групп: прессованная/литая рядом,
  Другое/Комплекс энерго свёрнуты, суммы Офис+Цех всех цветов.
- /warehouse/products/{id} — таблица по оригиналу: №, Цвет, Цена, Ед. изм.,
  Склад, Офис, Цех, В переложке, В задачах / В заказах, Добавить, Списать,
  история, min. Все цвета, включая отключённые; sorting/id.
- Склад в детализации = Офис+Цех+сохранённый третий склад, как в legacy.
  В скобках — эта сумма минус открытые отгрузочные задачи (type2/status0),
  НЕ резерв по всем заказам. Сумма обзора не включает выключенный третий склад.
- В заказах — заказано минус фактически отгружено в открытых статусах;
  каждая сторона агрегируется до соединения, дубли строк не множат суммы.
- В переложке — production_entries с количеством без accepted_by.
- Popup задач/заказов открывает даты, количества и ссылки на новые карточки заказов.
- /warehouse/variants/{id}/history — 50 записей на страницу, исходные даты,
  актор, склад, смена, количество, комментарий. Подписи событий как в legacy.
- min сохраняется blur/Enter (включая очистку); защита edit_version и audit каталога.
- Задачи: свежая потребность max(0,min − Цех + задачи − переложка), выбор,
  печать, создание заданий на производство с выбором пресса.
- /warehouse/products/{id}/production — задания, частичная выработка,
  частичная/полная приёмка из переложки и закрытие без прихода.
- /warehouse/products/inventory/{1|2} — печатные бланки инвентаризации,
  пустые графы Подсчет/Факт/В базе/Разница, параметры переложки; без цен.

## Транзакции и права

Приход/списание: блокировка Product, доменное изменение остатка, неизменяемый
warehouse_history. Приход со сменой дополнительно пишет расход сырья по рецепту:
component/output * quantity/ratio, только production=1, точная BigRational-арифметика,
округление до трёх знаков. Все эффекты в одной транзакции. Отсутствующий рецепт
сохраняет приход с предупреждением, как действующий legacy; нулевой выход/ratio
откатывают операцию. Штатные предупреждения табеля/форм не запрещают приход.
Дата выработки и списания сырья — дата изготовления 23:59:00.

UUID отправки + userId защищают повтор прихода, приёмки и выработки; повтор с
изменёнными данными отклоняется. Частичная приёмка уменьшает остаток черновика и
создаёт принятую часть, не увеличивая общую выработку. Закрытие без прихода
сохраняет компенсирующую запись выработки (как legacy), не меняя склад.

Просмотр: division101. Офис/Цех: группы1/2. Приход: division106 и группы1/3 либо
user31; списание: division106 и группа1; min: группа1.
Производство/приёмка: division320, как старые связанные обработчики321/322/324
(отдельного permission324 в импортированном справочнике нет).
Инвентаризация: группы1/3 или user31 дополнительно к division101.
Общий CSRF listener и RequestDtoResolver; DTO/User определяются по типу.
SQL в репозиториях/импорте, не в контроллерах. Цены и снимки заказов не меняются.

## Миграция и импорт

Version20261008170000 добавляет новые таблицы без правки текущих products.
Команда legacy:import-warehouse: однократный атомарный импорт с ID и исходным JSON,
chunk200, без удаления/перезаписи application products/orders/users. Повтор —
no-op под блокировкой warehouse_imports; если до первого импорта уже есть новые
операции в целевых таблицах, импорт отказывает, сохраняя их.

Импортировано: warehouse_history84745, shipping_tasks22896, shipping_items55646,
production_tasks5396, production_entries32515, raw_materials45,
raw_material_history47014, raw_material_balances30, production_recipes470,
shift_days1360. Нулевые даты → null, serialized массивы → JSON через
unserialize(allowed_classes=false), объекты запрещены.
До завершения импорта детализация и операции явно отказывают, без фиктивных нулей.

Старые складские остатки — начальный импортированный снимок, далее здесь живут
новые application-операции. Автоматической синхронизации с legacy нет.
Не переносились соседние самостоятельные разделы управления сырьём/табелями,
перемещения, возвраты, кассы; связанные данные и эффекты текущего экрана сохранены.
Общий production cutover не выполнялся.
