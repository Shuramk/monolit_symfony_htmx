# Верхнее меню

Шаблон `_navigation.html.twig`, стили `assets/styles/app.css`.
Внешний вид соответствует legacy `templates/tabbar.tpl` и `css/main.css`:
серая полоса пользователя 20px (имя слева, POST-выход с CSRF справа),
основные вкладки 28px, подменю 38px, шрифт вкладок Arial 20px.
Основной ряд занимает ширину окна; подменю собрано слева. Активный раздел —
серый фон и жирный текст, активный подпункт — белый фон.
На узких экранах каждый ряд прокручивается горизонтально, не переносится.
Шапка фиксирована; `.app-main` имеет верхний отступ 100px.

Пункты и их порядок берутся только из разрешённого пользователю `app_menu()`;
оно вызывается один раз при рендеринге. Служебной вкладки «Главная» нет в
производственном меню; маршрут migration_dashboard сохранён.
Активный раздел определяется по собственному URL либо URL его дочернего пункта,
с границей пути `/`, поэтому карточка/создание/редактирование остаются в разделе
«Заказы», а `/enterprise` выделяет «Настройки» и соответствующий подпункт.
Неперенесённые пункты сохраняют существующие legacy-ссылки. Права не расширяются.

Проверка: `tests/Controller/NavigationTest.php` — список, карточка, создание,
настройки, единственное выделение, CSRF/POST выхода, скрытие недоступного раздела.
Схема БД и импорт не менялись; запросов в контроллеры не добавлено.
